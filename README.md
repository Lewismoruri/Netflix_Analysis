**Project Overview**  
Analysis of Netflix titles dataset to derive key business insights. Focused on content trends, regional distribution, ratings, and visualization to support data-driven decisions.

### Project Highlights
- Utilized **SQL** to extract and query data.
- Transformed and filtered data using aggregating and filtering functions to improve reporting process.
- Loaded and visualized data with **Python** (pandas, matplotlib/seaborn) to identify key business intelligences that can improve sales performance and content strategy.

### Dataset
- **File**: `netflix_titles.csv`
- **Source**: Netflix titles (Movies + TV Shows)
- **Columns**: show_id, type, title, director, cast, country, date_added, release_year, rating, duration, listed_in, description

### Key Analysis Areas
- Content distribution (Movies vs TV Shows)
- Release year trends and catalog freshness
- Top producing countries
- Rating and genre analysis
- Duration patterns

### Technologies Used
- SQL (queries & aggregations)
- Python (pandas for cleaning/transformation, matplotlib/seaborn for visualization)
- Git & GitHub for version control

### Future Enhancements
- Dashboard (Power BI)
- Advanced NLP on descriptions
- Recommendation system insights
